# Research documentation

The research behind the platform. The documents stay where the analysis scripts write and link them;
this page is the entry point.

| Document | Content |
|---|---|
| [Project overview](../PROJECT_OVERVIEW.md) | the problem, the simulation loop, every algorithm (signals, preemption, VANET, navigation, incidents, GLOSA, GA, work zone), results, limitations, glossary |
| [Method](../method.md) | experimental method, configurations, metrics and statistics, per module |
| [Results and discussion](../results_discussion.md) | the result tables over 10 seeds with paired tests, and their interpretation (regenerated by `npm run sim:report`) |
| `results/summary.json`, `results/*.csv` | the stored experiment results shown on the Results page |
| In the dashboard | *Documentation* (formulas, architecture, limitations, future work), *Results*, *GA optimisation*, *Guided demo* |

Every figure quoted on the platform comes from the stored experiments. They are simulation results
for the stated scenarios, not guaranteed real-world performance.
